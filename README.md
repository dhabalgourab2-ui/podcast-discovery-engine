# Overview

Finding the right podcast shouldn't require browsing thousands of episodes.

The **Podcast Discovery Engine** is an open-source project that helps developers and users discover podcasts intelligently using semantic search, AI recommendations, creator relationships and structured metadata.

Instead of relying only on keyword search, this project focuses on understanding podcast content, speakers, topics, categories and creator relationships.

The project is inspired by **IndiTubeDb**, an AI-powered platform for discovering YouTube creators, podcasts and educational content.

🌐 Website

https://www.inditubedb.com

# Why Podcast Discovery Engine?

Millions of podcast episodes are published every year.

Users often struggle to answer questions like:

- Which AI podcasts should I follow?
- Which startup founders host podcasts?
- Which technology podcasts are beginner friendly?
- Which finance podcasts explain investing?
- Which Indian podcasts interview entrepreneurs?
- Which podcasts discuss Generative AI?

Traditional search engines return keyword matches.

Podcast Discovery Engine provides intelligent recommendations.

# Example API

Search Podcasts

GET

```
/api/v1/podcasts/search?q=artificial intelligence
```

---

Get Podcast

```
GET /api/v1/podcasts/{id}
```

---

Trending Podcasts

```
GET /api/v1/podcasts/trending
```

---

Categories

```
GET /api/v1/categories
```

---

Recommendations

```
GET /api/v1/recommendations
```
